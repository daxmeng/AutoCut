# 自动剪辑视频

```Mermaid
flowchart TD
    A[视频.mp4] --> B[FFmpeg 提取音频]
    B --> C[并行处理]
    C --> D[Whisper VAD 检测<br/>识别静音时间段]
    C --> E[语音转字幕<br/>生成 SRT 字幕]
    D & E --> F[FFmpeg 裁剪]
    F --> G[自动剪辑视频]
```

## 自动剪辑核心逻辑
- 超长静音： 删除 ＞0.8 秒 的静音 / 气口，保留正常短停顿
- 语音废内容：过滤 嗯/啊/然后 等口播水词；丢弃 ＜0.5 秒 的极短语音（人眼无法阅读）
- 劣质画面：自动识别并删除黑帧、模糊帧，过滤无效废镜头。
- 区间合并：自动合并重叠 / 相邻的删除区间，避免重复裁剪，提升效率。
- 语音识别变为文字
- 文字区间去除0.5秒，大模型语义重组 -> 混剪
